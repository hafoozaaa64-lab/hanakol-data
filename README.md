# hanakol-data

Public data for the app **هناكل ايه النهارده** (What to eat today).

- `prices.json` — approximate weekly ingredient prices in EGP, rebuilt every Friday by an automated job. Schema: see `SCHEMA.md`.
- `privacy.html` — the app's privacy policy (Arabic / English).

This repository contains data only. It holds no code secrets. Prices are approximate, collected from public sources, and may differ by shop and area.
